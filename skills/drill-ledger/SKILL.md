# drill-ledger — 演習台帳

実体: `ledger/tally.py`（集計）/ `questions.tsv`（問題マスタ）/ `rounds/`（解答ノート）
書式の詳細は `ledger/README.md`。

## 設計の芯 — 3つだけ

### 1. 正誤は自動判定する。人は「選んだ肢」だけタップする

問題マスタに正解を持たせ、選んだ肢から正誤を導く。

E資格では ❌ を手でタップさせていたため**付け忘れが27問**発生し、演習の終盤に
判定の正本を「解説の貼付有無」へ切り替える是正が必要になった。
**人が2回タップすると、1回は忘れる。** タップは減らす。

### 2. 確信度は1問目から取る

`🤔 自信なし` のチェックだけは人にしか付けられないので、これは残す。**最初の1問から。**

E資格では「たまたま正解」の記録を演習の終盤（本番7日前）に導入したため、
1周目の⭕がどれだけ本物だったのか分からなかった。逆行率36%という事後指標で
やっと気づいたが、User の実感は「**1周目がまぐれだった**」。
つまり忘却ではなく**測定の粗さ**が原因で、復習間隔をいじっても直らない問題だった。

### 3. どの誤答肢を選んだかを残す

これが `recall-drill` の燃料。**あなた個人の混同ペア**は、教材から一般論を作る
道具には決して作れない。ここが自作側の優位性の源泉なので、必ず残す。

## 4象限

|  | 確信あり | 確信なし 🤔 |
|---|---|---|
| **正解** | ✅ 定着 | ⚠️ **たまたま正解** |
| **不正解** | 🔴 **誤解** | ⬜ 未学習 |

- 🔴 **誤解** = 自信を持って間違えた。**知識が間違っている。** 概念の再学習が要る
- ⚠️ **たまたま正解** = 根拠がない。**本番で落とす最有力候補。** 根拠の言語化が要る
- **この2つは処方が違う。** 不正解だけを追うと ⚠️ が丸ごと見えなくなる

## 使うコマンド

```
python ledger/tally.py                 # 最新周回のサマリ（4象限・分野別・設問タイプ別・混同パターン）
python ledger/tally.py --round 1       # 周回を指定
python ledger/tally.py --compare 1 2   # 逆行率・転換率
python ledger/tally.py --drill         # 優先復習リスト
python ledger/tally.py --next 15       # 次に出す問題（想起テスト履歴と間隔反復を加味）
python ledger/tally.py --recall        # 想起テストの通算成績
python ledger/tally.py --detail        # 大問別の明細
```

## 台帳を作る手順

1. **問題マスタ `questions.tsv` を作る**（TSV / UTF-8 / タブ区切り）

   ```
   id	分野	型	正解	出典	メモ
   1-01-1	A 基礎	選択	C	問題集 p.12	用語の定義
   1-01-3	A 基礎	誤選択	D	問題集 p.13	最も不適切なものを選べ
   2-02-2	C 発展	記述	-	問題集 p.45	導出を書く
   ```

   - **id は `<大問>-<小問>`。** 大問側は解答ノートの `##` 見出しと一致させる
   - **型**: `選択` / `誤選択`（「最も不適切なものを選べ」型）/ `記述`
     → **`誤選択` を必ず分けて入れる。** これが設問反転の失点を数字にする唯一の手段
   - **正解**: 選択肢がなければ `-`

2. **解答ノートを生成する** — `rounds/round1/` に章ごとの md を置く

   ```markdown
   ## 1-01 用語と計算の基本

   ### (1)
   - [ ] A
   - [ ] B
   - [ ] C
   - [ ] D
   - [ ] 🤔 自信なし
   ```

   - 記述問題だけ `- [ ] ⭕ 正解` / `- [ ] ❌ 不正解` を置く
     （**無印を正解扱いにしない。** 未着手と区別がつかなくなる）
   - iPad/スマホからタップする前提。**1問あたり1〜2タップで終わる形を崩さない**

3. **User が解く** → 台帳を更新（Git 経由でどの端末からでも）

4. **集計して読む** → 結果は `recall-drill` と `study-review` の入力になる

## 読み方（Claude 側の判断基準）

- **「確信のある正解」の率**が実力。見かけの正答率との差が水増し分
- **分野別で低いほうから触る。** 高い分野は「今は触らない」であって「安全」ではない
  → 🟢を出した分野には**再測定の期限を切る**（E資格では🟢判定で放置した3分野が
     初見の通し演習で -18pt / -14pt / -9pt と崩れた）
- **逆行の内訳を見る。** 逆行のうち前周で🤔が付いていた割合が過半なら、
  それは忘却ではなく**まぐれの剥落**。解き直しを増やしても直らない
- **既出問題の正答率は実力ではない。** 初見で測れる機会（通し演習・模試）を
  本番の3週間前までに必ず1回置く
