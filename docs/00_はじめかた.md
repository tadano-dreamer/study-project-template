## 事前に用意するもの

| | |
|---|---|
| **試験名と本番日** | 申込は自分でやる（Claude はやらない） |
| **教材** | 問題集・テキストなど。買うのは自分 |
| **1〜2時間** | 初日だけ。2日目以降は週1〜2回で回る |

原本（本・PDF）は**リポジトリに入れません**。台帳にはページ番号だけ持ちます。

---

## 初日にやること

```bash
cp -r <このリポジトリ>/template  ~/study-<試験名>
cd ~/study-<試験名> && git init
powershell -NoProfile -ExecutionPolicy Bypass -File <このリポジトリ>/install.ps1
```

そのフォルダで Claude Code を開いて、**「◯◯試験の勉強を始めたい」**と言う。

以降はこう進みます。

| | やる人 | 内容 |
|---|---|---|
| **1. 聞き取り** | あなた | 本番日・使える時間・教材・合格ラインの4つを聞かれる。**まとめて1回だけ** |
| **2. 範囲を確定** | Claude | 公式サイトから出題範囲を取ってくる。**改訂の差分**も調べる |
| **3. 教材の目次を取る** | 半々 | 章立て・問題数。動画講座なら講座番号まで |
| **4. プレテスト** | **あなた** | **20〜30問を実際に解く**。ここだけは代われません（30分ほど） |
| **5. 計画を引く** | Claude | プレテストの弱い順に並べたガントが出る |

**4を飛ばさないでください。** ここで測った現在地が、全ての優先順位の根拠になります。
飛ばすと「どの分野が苦手か自分でも分からないまま最後まで走る」ことになります。

**プレテストのコツ**: わからない問題も**必ず一つ選んで「🤔自信なし」を付ける**。
空欄にすると未着手扱いになり、「まったく歯が立たない分野」という一番重要な情報が消えます。

**あなたが見るのは `wbs-gantt/wbs-gantt_v1.png` の1枚だけ**です。
（他のファイルは Claude が状態を保つためのもの。読まなくていいように作ってあります。）

| **覚えたか確認したい** | 「問題出して」と言えば、**あなたが間違えた問題**から弱点順に出題される |

スマホ・iPad から解きたいときは、GitHub に push して Git クライアント経由で同期します
（構成は `03_環境.md`）。ガントは PNG があるので GitHub 上でそのまま見られます。

## 遅れたとき

隠さなくて大丈夫です。Claude 側から声をかけます。

- **2週続けて黄信号 / 1回でも赤信号** になったら、Claude が**計画の引き直しを提案**します
- 提案は必ず3案。**うち1案は「まるごと捨てる案」**です
- 詰められ方は「**数字 + いつ何をやるかの宣言**」まで。罰はありません
- 宣言した内容は次回の冒頭で**必ず答え合わせ**されます

---

## 終わったら

本番が終わったら、**合否が出る前に**振り返りをやってください。
`template/retrospective/00_振り返り設計メモ.md` に手順があります。

結果を知った後の記憶は結果に引っ張られます（合格すれば全部正しかったことになる）。
**結果が入る前に証言を凍結する**のがこの手順の要点です。
