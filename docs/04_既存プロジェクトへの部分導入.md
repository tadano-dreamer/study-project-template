# 既存プロジェクトへの部分導入

> **これから始める人は [00_はじめかた.md](00_はじめかた.md) へ。** こちらは
> **すでに走っている学習プロジェクトに、使える部分だけ足したい人**向けです。

丸ごと乗り換える必要はありません。**走行中でも今日から効くもの**と、
**立ち上げ時にしか意味がないもの**があるので、先に仕分けます。

---

## 走行中でも効くもの / 効かないもの

| | 走行中の価値 | 理由 |
|---|---|---|
| **出題範囲との照合**（[02](02_初日ゲート.md) ゲート1） | ★**今すぐやる価値がある** | 30分で終わる。改訂の追加項目を知らないまま走るのが一番怖い |
| **確信度つきの記録**（[ledger](../template/ledger/README.md)） | ★**今日から効く** | 「正解したが自信なし」を分けるだけ。過去分は遡れないが、今後の記録は変わる |
| **設問タイプの記録**（誤選択型） | ★効く | 「最も不適切なものを選べ」で落とす癖を数字にする。列を1つ足すだけ |
| **ガント**（[wbs-gantt](../template/wbs-gantt/)） | ○ 効く | 今の残り期間で引き直せばよい。ベースラインは引いた日を起点にする |
| **想起テスト**（`recall-drill`） | ○ 台帳ができてから | 台帳が入力なので、先に台帳を整える |
| **教材の作り方**（`study-material`） | ○ 部分的に | 一問一答を台帳に入れる方針だけ拾うと効きやすい |
| **リプランの発火条件**（`study-replan`） | ○ 効く | ルールを1つ決めるだけ。ファイルは不要 |
| **プレテスト**（ゲート3） | △ 形を変えて | 立ち上げ用。走行中なら「今の実力測定」として1回やる |
| **フォルダ構成の移行** | ✗ **おすすめしない** | 得るものが少なく、壊すリスクが大きい。部品だけ足す |
| **`~/.claude/skills/` へのスキル導入** | ⚠️ 影響範囲に注意 | **グローバル**なので他のプロジェクトにも効く。同名スキルは上書きされる |

**迷ったら上2つ（範囲照合・確信度）だけやってください。** 費用対効果が突出しています。

## なぜこの形か

| | 理由 |
|---|---|
| **clone を明示している** | URL だけ渡すと GitHub の HTML ページしか読めず、推測で提案されます |
| **「まず 1〜4 だけ」** | いきなり実装させないための歯止め |
| **現状を書く欄がある** | 走行中かどうかで、採用すべきものが変わります。空欄だと提案の精度が落ちます |
| **スキル導入を質問扱い** | `~/.claude/skills/` はグローバル。他プロジェクトへ波及し、同名は上書きされます |
| **上書き禁止・事前コミット** | 走行中のプロジェクトを壊さないため |
