| 優先 | ゴール | 捨てるときの扱い |
|---|---|---|
| 1 | | 捨てない |
| 2 | | 遅れたら Phase 2（本番後）へ送る。再開点: |

> ★ 軸を捨てたら、**この節も同時に書き換える。**

## §4 教材のフォーマット

学習資料は次の構成で書く（変更するならここを直す）。

```markdown
# {トピック名}
## 概要
## キーコンセプト   ← 「用語: 定義」形式
## 数式・直感
## 想定Q&A          ← Q: ...? / A: ... 形式
## 関連問題
## 試験での出題ポイント
```

**保存先**:
- 解釈ノート: `materials/{分野}/`
- 想起テスト用の一問一答: `ledger/` に台帳として持つ（別ファイルにしない）
