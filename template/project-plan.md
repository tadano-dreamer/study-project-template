## §4 教材のフォーマット

**形の正本はここ。** `materials/README.md` は置き場所と役割だけを持ち、雛形はここを指す（2か所に持つと食い違う）。
読むもの（インプット）は「問題の解説」、解くもの（アウトプット）は「一問一答」、と分ける。

### 問題の解説の形

**演習を採点したあとの解説は、この形で最初からファイルに書く。**
「読む → 分からない所をチャットで聞く → 追加の説明をもらう」の往復をなくすため。

| 項目 | 決まり |
|---|---|
| 置き場所 | `materials/問題の解説/`。演習1回分（1章分）で1ファイル: `{演習の名前}_解説.md`。一問一答は `一問一答_<日付>_解説.md` |
| 並び | ① 誤答・未回答 → ② 🤔自信なしの正解 → ③ 自信ありの正解（確認用）。冒頭に全問の一覧表（問・分野・論点・正解・選んだ肢・結果） |
| 深さ | ①② は下の雛形をフルで書く。③ は「肢の表」と「根拠の1行」だけ（例題なし） |
| 例題 | **3問・易しい順。答えは各問のすぐ下に書き、折りたたまない**（読むのがメイン） |
| 問題の呼び方 | User に見える所は、教材と同じ呼び方（`CLAUDE.md` 守ること 2） |
| 一覧表のリンク | 「問」の列は、その問の解説の見出しへのリンクにする。表の中では別名の区切りを `\|` と書く。見出しに太字や絵文字を入れない（リンク先の文字列が崩れやすい） |
| 数式 | インライン数式は **`$` の内側の両端に空白を入れない**（Obsidian で生の文字になる） |
| 数値例の数 | 式や表に出す数は、記号と出どころを添える。答えに出てくる量は、定義の式をその節の中で1行書いてから使う |
| 問題文 | **教材の本文は転記しない**（著作物）。「何が問われたか・与えられた数値」だけを自分の言葉で1〜2行 |
| 手書きとメモ | 手書きページと ✍️ メモを読んで分かった取り違えは、その問の解説に書く（「あなたのメモ」として日付つきで引く） |
| 分けて書く | 1回分が長いときは ①→②→③ の順に約10問ずつ書いてコミットする（着手前に分割の宣言をする） |
| 一問一答の解説 | **論点ごとに節**（同じ論点のカードをまとめる）。暗記カードは肢が無いので、肢の表の代わりに「答え → あなたのメモ → 組み立て方」。解説を書いた問いは、素材の折りたたみの末尾に `> 📖 詳しい解説: [[…]]` を1行足す。前に解説した論点でまた落としたら、新しく書かずにリンクと「今回の取り違え」1行で済ませる |

**雛形**（①② の1問ぶん）

```markdown
## {教材と同じ呼び方の問番号} {論点名}

**正解 X**（選んだのは Y／🤔）

> {何が問われたか・与えられた数値を1〜2行。本文は写さない}

{何を取り違えたかを1文。「〜という1点のミスです」のように、ずれた場所を1か所に特定する}

| 肢 | 計算 または 記述 | 判定・どこで取り違えるか |
|---|---|---|
| A | … | … |
| **正解** | … | **正解** |
| **選んだ肢** | … | … ← あなたの誤答 |

**根拠の1行**: {答えを選べる理由を1行}

### {仕組みの見出し（例: なぜ「足し算」は標準偏差に効かないのか）}

- 用語は初出で1文の定義を添える
- **小さな数値例を表で手を動かして確かめる**
- 式は LaTeX、式のすぐ隣に意味。解き方は「手順1・2・3」の形にする
- 検算・符号の確かめ方を1行
- 前に解いた問題と同じ考え方なら、問番号でつなぐ

### 追加の例題

**例1** {易しい。同じ手順をそのまま使う}

→ {答えと1〜2行の解説。折りたたまない}

**例2** {逆算・空欄補充・符号の罠など、向きを変えた問題}

→ …

**例3** {続きの問題（同じデータで一歩先）か、「誤っているもの」型の正誤判定}

→ …
```

**書き方の規則**
- 誤答の肢は**逆算して、どの計算・どの読み違いから出た数字かを表に書く**（ほとんどの肢は「1か所だけ取り違えた計算」と一致する）
- 🤔 で正解した問題は、誤答の代わりに「**根拠を言えるようにする**」ことを目標にし、他の肢がなぜ誤りかを表にする
- 例題の数値は Claude が作る。**計算は書く前に検算する**
- **❌ 思い込みは、実際に選んだ肢か、手書き・メモがあるときだけ書く。** 根拠の無い思い込みを作らない

### 追加解説の図

チャットで追加解説を頼まれたら、図を SVG 1枚で `materials/図解/` に描き、Claude 用のメモを `materials/図解/追加解説メモ.md` に1節足す。**解説ファイルは書き換えない**（`CLAUDE.md` 守ること 12）。
図の名前は `{演習の名前}_{問番号}_{論点}.svg`。

### 一問一答の形

| 項目 | 決まり |
|---|---|
| 2種類 | **① 類題**（間違えた問題の確認）／**② 暗記カード**（計算なしで即答すべき公式・定義・考え方） |
| 計算 | **手書きが要る計算は出さない。暗算まで。** 計算の取り違えは「どの式になるか」を選ぶ形にする |
| 解く場所 | 日替わりページ `一問一答/毎日/YYYY-MM-DD.md`。**User は pull → 解く → push だけ。解いたあとの連絡はしない** |
| 作る人・時刻 | クラウドの定期実行（時刻は立ち上げのときに聞く。指示文は `docs/一問一答の定期実行.md`） |
| 量 | §3「期間から決めること」で決めた数。`ledger/daily.py` の `DEFAULT_CARDS`・`DEFAULT_RUIDAI` に書く。日付をまたいで解いた日が2日続いたら、Claude から減らす案を出す（`python ledger/daily.py pace`） |
| ① の答え方 | 選択肢をタップ＋迷ったら🤔。正誤は `questions.tsv` の `正解` と照らして自動で判定。解説は折りたたみ |
| ② の答え方 | **選択肢にしない。** 頭の中で答える → 折りたたみの答えを開く → ⭕/❌ を自分でタップ＋迷ったら🤔。**答えの頭に「⭕ の線」（ここまで言えたら⭕）を1行書く** |
| メモ欄 | 各問に ✍️。何が分かって何が分からないかを書いてもらう。Claude は解説を書くときに全部読む。**ページの冒頭に所見は書かない** |
| 素材 | ① `一問一答/類題/<演習の名前>.md`（**採点したセッションが、誤答1つにつき1問**・解説の例題とは別の数値）／② `一問一答/暗記カード/<分野名>.md`（弱い分野から） |
| 記録 | タップは定期実行が `ledger/recall-log.tsv` に入れる（`形式` は `類題`／`暗記`）。出す順は `tally.py` の4象限と間隔反復 |

**素材の書き方**
- `## {id}` の見出しごとに1問。類題は 問い → `- A …` の選択肢 → `> [!note]- 解説`（1行目は `**正解 X**`）。暗記カードは 問い → `> [!success]- 答え`（1行目は `**⭕ の線**: …`、続けて答えを1〜2行）
- id は `類題-{分野名}-NN` ／ `暗記-{分野名}-NN`。`questions.tsv` の `出典` は `類題 {演習の名前}` ／ `暗記カード {分野名}`、`型` は類題が `選択`／`誤選択`、暗記カードが `暗記`（`正解` は `-`）
- 類題は **`元問題` 列に元の問題 id を書く**。周回に着手記録が無いあいだは元問題の象限を引き継いで出る。暗記カードは `元問題` を空にする
- 類題の誤答の肢は「1か所だけ取り違えた式」にする。**1分野に誤選択を1問以上**
- 素材を足したら `python ledger/daily.py check`
