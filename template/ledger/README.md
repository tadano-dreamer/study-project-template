# 演習台帳

正誤だけでなく**確信度**も取り、**正誤 × 確信の4象限**で診断する。
設計の根拠は `../../docs/01_設計思想.md` 判断3・判断5。

```
ledger/
├── questions.tsv      問題マスタ（Claude が作る。正解を持つので学習中は開かない）
├── rounds/
│   ├── round1/*.md    1周目の解答ノート ← ★人が触るのはここだけ
│   └── round2/*.md    2周目
├── recall-log.tsv     想起テストの正答率（recall-drill が追記）
└── tally.py           集計
```

---

## 4象限

|  | 確信あり | 確信なし 🤔 |
|---|---|---|
| **正解** | ✅ 定着 | ⚠️ **たまたま正解** |
| **不正解** | 🔴 **誤解** | ⬜ 未学習 |

- 🔴 **誤解** — 自信を持って間違えた。**知識そのものが間違っている。** 概念の再学習が要る
- ⚠️ **たまたま正解** — 当たったが根拠がない。**本番で落とす最有力候補。** 根拠の言語化が要る

**この2つは処方が違う。** 不正解だけを追うと ⚠️ が丸ごと見えなくなる。

## 解答ノートの書き方

**タップするのは「選んだ肢」と「🤔自信なし」だけ。正誤は自動判定される。**

```markdown
## 1-01 用語と計算の基本

### (1)
- [ ] A
- [ ] B
- [x] C          ← 選んだ肢
- [ ] D
- [ ] 🤔 自信なし

### (2)
- [x] A
- [ ] B
- [ ] C
- [ ] D
- [x] 🤔 自信なし   ← 自信がなければタップ
```

### 選択肢のない問題（記述・計算）だけ手で付ける

```markdown
### (3)
- [ ] 🤔 自信なし
- [x] ⭕ 正解
```

`⭕` か `❌` の**どちらかを必ず**タップする。
無印を正解扱いにすると**未着手と区別がつかなくなる**ため。

### 見出しの規則

- `## <大問id> <タイトル>` — id は `questions.tsv` の `id` の大問部分と一致させる
- `### (n)` — 小問番号。台帳上の id は `<大問id>-<n>` になる

## 問題マスタ `questions.tsv`

タブ区切り・UTF-8。

```
id	分野	型	正解	出典	メモ
1-01-1	A 基礎	選択	C	問題集 p.12	用語の定義
1-01-3	A 基礎	誤選択	D	問題集 p.13	最も不適切なものを選べ
2-02-2	C 発展	記述	-	問題集 p.45	導出を書く
```

| 列 | 意味 |
|---|---|
| `id` | `<大問>-<小問>`。解答ノートの見出しと対応させる |
| `分野` | 集計の単位。初日ゲート2で作った分野リストを使う |
| `型` | `選択` / `誤選択` / `記述` |
| `正解` | 選択肢がなければ `-` |
| `出典` | 後で解説を引くため |
| `メモ` | 一覧に出る短い説明 |

### ★ `誤選択` を必ず分ける

「**最も不適切なものを選べ**」型を `誤選択` として区別する。
これが**設問反転の失点を数字にする唯一の手段**。

E資格では、この型で落とす癖に対策を決めた**後**に、また同じ型で落とした。
「注意しよう」では直らなかった。**測って数字にして、想起テストに混ぜる**のが処方。

## コマンド

```bash
python tally.py                 # 最新周回のサマリ
python tally.py --round 1       # 周回を指定
python tally.py --compare 1 2   # 逆行率・転換率
python tally.py --drill         # 優先復習リスト
python tally.py --next 15       # 次に出す問題（間隔反復を加味）★recall-drill が使う
python tally.py --recall        # 想起テストの通算成績
python tally.py --detail        # 大問別の明細
```

### 出力の読み方

- **「確信のある正解」の率が実力。** 見かけの正答率との差が、そのまま水増し分
- **分野別は低いほうから触る。** 高い分野は「今は触らない」であって「安全」ではない
- **逆行の内訳を見る。** 逆行のうち前周で🤔が付いていた割合が過半なら、
  それは忘却ではなく**まぐれの剥落**。解き直しを増やしても直らない
- **混同パターン**は「あなたが実際に取り違えたペア」。想起テストの対比表はここから作る

## 想起テストの記録 `recall-log.tsv`

`recall-drill` スキルが1行ずつ追記する。**手で書いてもよい。**

```
日付	id	結果	確信	形式
2026-09-09	1-01-2	o		対比
2026-09-09	2-01-3	x		反転訓練
```

- 結果: `o` = 正解 / `x` = 不正解
- 確信: `?` = 自信なし / 空 = 確信あり
- 形式: 対比 / 根拠説明 / 概念 / 反転訓練 / 一問一答

### 間隔反復のしくみ

**確信ある連続正解**の回数だけ、次に出るまでの間隔が伸びる（1 → 2 → 4 → 8 → 16 日）。
想起テストで落とすと、その問題は象限が1段昇格して優先度が上がる。

`--next` はこれを加味して出題キューを返す。**キューの順に出す。自分で選び直さない。**

## サンプルデータについて

`questions.tsv` と `rounds/` には**動作確認用のサンプル12問**が入っている。
新しいプロジェクトを始めるときは中身を捨てて、自分の問題集に置き換える。
`tally.py` の動きを見たいときは、そのまま `python tally.py` を叩けば全機能が動く。
